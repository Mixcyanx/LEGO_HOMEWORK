## 專案儲存方式與檔案架構說明 (How This Project is Stored)

本專案採用現代前瞻的前端模組化、零外部依賴（Zero-dependency）結構儲存於本地工作目錄中，確保在任何電腦或離線環境下皆能立即開啟且完整呈現所有視覺與動態效果。

### 1. 專案實體目錄結構
```text
20261001作業/
│
├── index.html          # 網頁主要結構與內容（語意化 HTML5、高解析度 SVG 樂高人偶、故事與象徵意涵）
├── style.css           # 樣式表（毛玻璃質感 Glassmorphism、3D 視差、CSS 動畫、響應式 RWD）
├── script.js           # 動態互動腳本（Web Audio 原生音效合成、Canvas 粒子系統、3D 傾斜、抽籤邏輯）
└── Readme.md           # 專案儲存說明、作者身分資訊、設計理念與 Prompt 指令紀錄文件
```

### 2. 檔案職責與儲存特點
1. **`index.html` (內容與結構層)**：
   - 採用語意化標籤（`header`, `main`, `section`, `footer`）。
   - 以高精緻度的向量 SVG 手工刻劃出經典樂高人偶（包含頭部 Stud 凸粒、經典微彎嘴角表情、梯形軀幹、活動手臂、手握金色積木、腳底契合凹槽）。
   - 完整收錄「故事驅動」的 1978 年 Jens Knudsen 誕生歷程與四大幸運象徵文案。
2. **`style.css` (視覺設計與美學層)**：
   - 採用質感深色調（Obsidian Dark `#090C14`）襯托樂高經典黃（`#FFD500`）、紅（`#EF4444`）、藍（`#2563EB`）的明亮色彩。
   - 導入毛玻璃特效（`backdrop-filter: blur`）、CSS 3D 視角變形（`perspective: 1200px`）以及純 CSS 刻劃的 3D 積木按鈕與 Studs 陰影。
   - 支援完整 RWD 響應式佈局，適配桌機、平板與智慧型手機螢幕。
3. **`script.js` (動態腳本與多媒體互動層)**：
   - **完全自給自足的原生技術**：不依賴任何外部音檔（MP3/WAV），利用瀏覽器原生 **Web Audio API** 振盪器與噪聲濾波器即時合成清脆的樂高積木「喀噠（Snap）」扣合與魔法音效。
   - **HTML5 Canvas 動態粒子系統**：常態飄浮微型 Stud 粒子與點擊爆破的星芒彩紙微粒。
   - **3D 視差追蹤**：依滑鼠位置即時計算 `rotateX` 與 `rotateY` 傾斜角度。
4. **`Readme.md` (技術規格與歷程文件)**：
   - 詳實記錄作業要求、Prompt 指令下達過程、執行規劃與存檔說明。

## 幸運物設計理念與故事驅動 (Story & Meaning)

### 為什麼選擇「樂高人偶 (LEGO Minifigure)」作為幸運物？
> **「跌碎了，重新拼起來就好。」**

1. **誕生故事 (1978 年 Jens Nygaard Knudsen 的初心)**：
   1978 年，樂高設計師 Jens Knudsen 創造了高度僅 3.8 公分的人偶。中性無特定種族的明亮黃色微笑，不被任何現實標籤定義，讓世界上每個握著它的人都能投射自己的夢想。
2. **四大幸運象徵意涵 (Symbolic Pillars)**：
   - 🧩 **拼湊與韌性 (Resilience)**：人生難免遇到挫折摔落一地，但樂高永遠不怕散開。零件拾起重新卡合，就能以更堅實的姿態重啟。
   - 🚀 **自我定義的勇氣 (Identity)**：更換帽子與配件，今天就能是探索宇宙的太空人、工匠或魔法師，象徵生命擁有無限可能。
   - 😊 **保持微笑的樂觀磁場 (Optimism)**：永恆的微笑弧度，是身處高壓時撫摸手心能帶來平靜的幸運錨點。
   - 🧱 **一步一腳印的基石 (Foundations)**：雙腳精準契合每一顆積木凸粒，象徵好運是由日常扎實努力一磚一瓦砌成。

## 步驟三：Prompt 下達指令紀錄 (Prompt Engineering & Script Spec)

依據作業規範「步驟三：在專案最後下達精準 Prompt，規劃並產生動態互動腳本」，本專案下達之完整 Prompt 如下：

### 🎯 下達之精準 Prompt
```text
請幫我規劃並製作這個幸運物網頁的動態互動效果，包含滑鼠懸停與點擊動畫。
```

### 🛠️ 動態互動腳本工程規劃與落地清單：
依據上述 Prompt，本專案在 `script.js` 與 `style.css` 中具體實作了以下 6 大互動模組：

| 互動模組 | 技術實現機制 | 使用者體驗回饋 |
| :--- | :--- | :--- |
| **1. 3D 視差傾斜 (Mouse Tilt)** | 監聽 `mousemove` 游標相對展示台與卡片中心的偏移百分比，動態運算 `rotateX/Y` | 滑鼠懸停時展示台與卡片產生極富質感的 3D 傾角與微光澤移動 |
| **2. 點擊爆破微粒 (Particle Burst)** | HTML5 Canvas 向量粒子渲染，包含物理重力下墜與微型積木旋轉 | 點擊人偶或抽籤按鈕瞬間發射金黃、鮮紅、湛藍的積木彩紙微粒 |
| **3. 樂高積木音效 (Snap Sound)** | 瀏覽器原生 Web Audio API，以雙振盪器與指數包絡模擬塑膠卡榫扣合聲 | 點擊與切換造型時發出無延遲、逼真的「喀噠」塑膠清脆碰撞聲 |
| **4. 模組化拆解透視 (Exploded View)** | CSS 3D Transforms 配合 `translateY` 狀態分離動畫 | 點擊按鈕使人偶頭部、驅幹、雙腿分離飄浮，直觀展示模組化拼裝結構 |
| **5. 四套幸運外觀切換 (Skin Switcher)** | 動態操作 SVG DOM 漸層、胸前印花、頭戴配件與手持幸運道具 | 提供「經典守護者」、「1980 太空探索」、「賽博造夢者」、「奇幻魔法師」一鍵切換 |
| **6. 每日樂高幸運籤 (Fortune Box)** | 亂數抽籤演算，結合晃動動畫（CSS Keyframes Shake）與翻轉展演 | 點擊立體積木按鈕晃動抽籤，隨機生成專屬幸運人偶角色、守護金句與幸運色 |

## 本地瀏覽與開啟方式 (How to Run)

本專案無需安裝 Node.js、Python 或任何伺服器環境：
1. **直接開啟**：
   - 在檔案總管中，直接雙擊 `index.html` 即可於 Chrome / Edge / Safari / Firefox 瀏覽器中開啟。
2. **VS Code 開啟（推薦）**：
   - 使用 VS Code 開啟資料夾 `20261001作業`。
   - 安裝並啟用 `Live Server` 擴充套件，在 `index.html` 按右鍵選擇「Open with Live Server」。
3. **音效體驗說明**：
   - 瀏覽器為防止網頁突發噪音，通常要求使用者與頁面發生第一次點擊互動後才會啟用音效（此為標準安全規範）。點擊網頁任一按鈕或頂部「音效 ON」按鈕即可沉浸式體驗積木聲音。
