ORIGIN & HERITAGE

從一顆小黃頭開始的傳奇

1978
📐

設計大師 Jens Knudsen 的初心

在 1978 年之前，樂高積木世界裡沒有真正靈活的居民。設計師 Jens Nygaard Knudsen 經歷無數次原型試驗，決定打破傳統，創造出一個腰部、手臂、腿部皆可旋轉活動，且手部能緊扣所有樂高配件的小人偶。

模組化設計革命
WHY YELLOW?
🎨

不設限的中性黃：每個人都是主角

樂高團隊選擇了純粹明亮的經典黃色，且僅用兩顆黑點與一抹微彎嘴角作為表情。這種「中性與包容」的設計，不代表任何特定種族或偏見，讓世界各地的每位玩家，都能把自己的靈魂與夢想投射進人偶中。

SYMBOLIC MEANING

為什麼樂高人偶是我的幸運物？

這不只是一件玩具，它是生活哲學的微縮映射，四大象徵帶給我跨越逆境的強大信念。

01 🧩

拼湊重組的韌性 (Resilience)

「掉在地上摔散了，重新拼起來就好。」

日常難免遭遇挫折與支離破碎的低潮。但樂高人偶最神奇之處在於：它永遠不怕散開。零件掉了可以找回，骨架鬆了可以重裝，甚至能換上更堅固的新裝甲。它象徵著跌倒後永不言棄、隨時重啟的修復力。

  • 面對失敗的從容心態
  • 隨時組裝更強大的自己
02 🚀

隨時定義自我的勇氣 (Identity)

「今天想成為誰，就換上什麼裝備。」

同一個黃色臉孔，換上太空帽就是宇宙先鋒；換上盔甲就是英勇騎士；穿上工裝就是城市築夢者。它提醒我不要被現實框架所拘束，人生有上萬種身分等待探索，只要心中有熱情，你就是自己故事的主角。

  • 突破既定標籤與限制
  • 無限可能的創造與多樣性
03 😊

保持童真的樂觀磁場 (Optimism)

「嘴角上揚微彎，好運自然會拼合。」

經典樂高人偶臉上永遠掛著一抹純真、堅定的微笑。每當焦慮煩躁時，看著它毫不動搖的笑容，就像在對自己輕聲打氣：「別慌，一切都能拼出好結果！」以正向心態吸引幸運，是最強大的心靈護身符。

  • 穩定情緒的心靈錨點
  • 以微笑吸引良善與幸運
04 🧱

一步一腳印的厚度 (Foundations)

「幸運不是偶然，而是一磚一瓦的積累。」

人偶雙腳的凹槽，能嚴絲合縫地扣合每一顆樂高積木的圓柱凸粒（Studs）。這象徵著好運並非天外飛來，而是來自平日扎實打底、腳踏實地的每一步積累。底座越穩，能建造的夢想城堡就越壯闊。

  • 每一分專注都是幸運積木
  • 堅實站立於自己的舞台

# 作業指定下達之精準 Prompt 指令：
> 請幫我規劃並製作這個幸運物網頁的動態互動效果，包含滑鼠懸停與點擊動畫。

📋 互動腳本規劃與實作成效清單：

🖱️
1. 3D 視差傾斜 (Mouse Tilt)

監聽滑鼠座標，讓展示台與人偶依游標位置呈現細緻的 3D 傾斜與環境光影連動。

💥
2. 點擊爆破微粒 (Particle Burst)

點擊人偶時透過 HTML5 Canvas 即時發射金色四角星與圓形積木粒子特效。

🔊
3. Web Audio 原生音效 (Lego Snap Sound)

使用瀏覽器原生 Web Audio API 合成擬真的樂高積木「喀噠 (Snap)」扣合音效。

🧩
4. 模組化拆解動畫 (Exploded View)

點擊「零件拆解透視」，頭部、軀幹、雙腿分離飄浮，具體展現樂高模組哲學。

👕
5. 造型外觀動態切換 (Skin Switcher)

經典守護者、1980 太空人、賽博造夢者、奇幻魔法師一鍵平滑過渡替換色彩與印花。

🥠
6. 每日幸運籤抽籤邏輯 (Fortune Generator)

配合震動反饋與翻轉卡片動畫，動態產生象徵箴言與每日幸運配色。
